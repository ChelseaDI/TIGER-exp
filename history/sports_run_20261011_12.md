## 5. 推荐模型训练（sid_nc）

```bash
cd /home/liuxuedi/projects/TIGER-val
nvidia-smi -i 0
ls ../LLM/t5-base/config.json
SPORTS_LOG="logs/sports/train_sid_nc_$(date +%Y%m%d_%H%M%S).log"

nohup env CUDA_VISIBLE_DEVICES=0 TOKENIZERS_PARALLELISM=false WANDB_DISABLED=true \
  python -u main.py \
  --dataset "Sports and Outdoors" --token_type sid_nc --K 256 --D 3 \
  --plm_dir ../LLM --plm_name t5-base --tokenizer_plm sentence-t5-base \
  --output_dir checkpoints_sports --precision fp32 \
  --batch_size 16 --gradient_accumulation_steps 16 \
  --epoch 200 --max_steps -1 --lr 0.0005 --optimizer adamw_torch \
  --weight_decay 0.01 --lr_scheduler_type cosine --warmup_ratio 0.01 \
  --max_len 20 --max_sent_len 512 \
  > "$SPORTS_LOG" 2>&1 < /dev/null &
echo $! > logs/sports/train_sid_nc.pid
realpath "$SPORTS_LOG" > logs/sports/train_sid_nc_latest_log.txt
tail -n 50 -F "$(cat logs/sports/train_sid_nc_latest_log.txt)"
```

有效 batch=256；FP32；按 epoch 训练，最多 200 epochs；每个 epoch 验证，连续 10 次验证损失未改善早停，结束后保存最佳模型。
日志关闭了训练进度条，可能较长时间无新增；`WANDB_DISABLED` 弃用提示不影响本次运行。
训练在 epoch 41 早停；总耗时 72888.715 秒，最低验证损失为 1.811791181564331（epoch 31）。
模型目录：`checkpoints_sports/sid_nc/Sports and Outdoors_sentence-t5-base/K=256_D=3/`。
