## 6. 推荐模型训练

```bash
cd /home/liuxuedi/projects/TIGER-val

nohup setsid env \
  CUDA_VISIBLE_DEVICES="$(nvidia-smi -i 0 --query-gpu=uuid --format=csv,noheader)" \
  python -u main.py \
  --dataset "Toys and Games" --token_type sid_nc --plm_name t5-base \
  --batch_size 64 --gradient_accumulation_steps 4 \
  --lr 0.0005 --max_steps 200000 --precision fp32 \
  --output_dir checkpoints_toys_lr001_sid \
  > train_log/toys_recommender.log 2>&1 < /dev/null &
echo $!
tail -n 30 -F train_log/toys_recommender.log
```

有效 batch=256；预训练 t5-base、用户前缀关闭、逗号分隔，按最低验证 loss 选模型，连续 10 次验证未改善早停。
结果：epoch 38 结束，耗时 21935.9813 秒；最佳验证 loss=1.8336704969406128（epoch 28，checkpoint-11963）。
